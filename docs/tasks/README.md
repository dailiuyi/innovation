# 跨会话任务

复杂或跨会话工作从 [模板](template.md) 复制到 `docs/tasks/active/<日期>-<任务名>.md`。小改动不强制创建任务文档。每个任务指定一位负责人，记录目标、边界、验收、进展、决定、证据和下一步；不保存密码、会话令牌或原始私密日志。

恢复顺序：读任务记录和知识入口，检查当前 Git 状态与相关代码，核对证据的源码指纹，然后执行下一项工作。发现用户修改时保留并重新判断；聊天摘要和已勾选的任务不能代替代码证据。

Symphony 任务先按 [Agent 工作流入口](../17-agent-workflow.md) 判断职责；任务 Markdown 只用于交接，不能代替工作区外的 plan.json/state.json。接手时记录 Issue/PR、完整 SHA、外置计划位置、runId、检查轮次、交付结果、用户授权和下一位负责人。只被要求“看看进度／接手了解”时只读；review/blocked 终态不能靠新会话、重新加 ready 或修改文档勾选恢复。重新执行必须有用户明确要求，并通过 ResumeTask 留下上一轮记录。

在阶段结束或中断前更新记录；失败写清原因和重现方式。完成后移到 `docs/tasks/completed/`，保留验收摘要与限制；把持续有效的决策提取到 [决策记录](../decisions/README.md)。归档任务只描述当时交付，不继续维护成第二份功能规格。后续验收通过链接补充，不把旧记录中的待验收状态当作当前状态。

已归档的 [开发协作讨论](completed/2026-09-19-collaboration-discussion.md) 保留当时决策与首页视觉审核范围；当前执行规则以对应手册为准。
