# 跨会话任务

复杂或跨会话工作从 [模板](template.md) 复制到 `docs/tasks/active/<日期>-<任务名>.md`。小改动不强制创建任务文档。每个任务指定一位负责人，记录目标、边界、验收、进展、决定、证据和下一步；不保存密码、会话令牌或原始私密日志。

恢复顺序：读任务记录和知识入口，检查当前 Git 状态与相关代码，核对证据的源码指纹，然后执行下一项工作。发现用户修改时保留并重新判断；聊天摘要和已勾选的任务不能代替代码证据。

在阶段结束或中断前更新记录；失败写清原因和重现方式。完成后移到 `docs/tasks/completed/`，保留验收摘要与限制；把持续有效的决策提取到 [决策记录](../decisions/README.md)。归档任务只描述当时交付，不继续维护成第二份功能规格。
